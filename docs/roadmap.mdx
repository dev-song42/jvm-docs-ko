- **작성 전**: 공개할 문서는 아직 없으며 주제·범위만 계획된 상태입니다. 작업 브랜치에 비공개 초안이 있을 수 있습니다.
- **작성 중**: 초안을 작성하고 있으며 `draft: true`인 문서는 공개 사이트에서 제외합니다. 진행 상태 공개는 별도로 요청한 경우에만 반영합니다.
- **작성 완료**: 검토를 마치고 공개 문서로 연결한 상태입니다.
- **필수 / 심화**는 작성 상태가 아니라 학습 깊이입니다. 각 부의 필수 항목을 먼저 읽고 심화는 필요할 때 돌아와도 됩니다.
- 각 행에는 **문서 제목, 포함·제외 범위, 주요 공식 자료**를 함께 적습니다. 자료 링크는 공개된 한국어 글 링크가 아닙니다.
- 앞선 필수 내용을 전제로 순서대로 읽되, 각 카테고리의 선수 지식을 확인합니다. 자료 조사·초안 작성 후 작성자가 읽고 예제를 확인하며 다듬습니다.

### 출처와 버전 기준

Java는 참고 자료를 종합한 독립적인 해설이고, Spring·Spring Boot는 공식 문서 선별 번역입니다. 이 구분은 템플릿과 문서 유형에도 유지합니다.

아래 출처는 **예정 범위의 대표 자료**입니다. 글을 작성할 때 읽은 페이지·절, 추가 자료, 기준 버전과 검토일을 기록합니다. Spring 문서의 `6.2`·`3.5` 웹 링크는 갱신될 수 있으므로, 실제 번역문은 [Framework v6.2.19 문서 소스](https://github.com/spring-projects/spring-framework/tree/v6.2.19/framework-docs/modules/ROOT/pages)와 [Boot v3.5.16 문서 소스](https://github.com/spring-projects/spring-boot/tree/v3.5.16/spring-boot-project/spring-boot-docs/src/docs/antora/modules)의 경로·절·태그 또는 커밋으로 고정합니다. 원문 구간과 다른 해설을 혼합해 공식 번역인 것처럼 표시하지 않습니다.

## 1부: Java 21

Java는 공식 자료로 사실을 확인하고 설명 순서·문장·예제를 직접 구성하는 **자료 기반 해설(개인 학습 정리)**로 작성합니다. 여러 문서의 문단을 번역해 이어 붙이지 않습니다. 아래 링크는 참고 자료이며 일괄적인 번역·재배포 허가를 뜻하지 않습니다. dev.java 등 계속 갱신되는 자료도 예제와 동작은 Java 21에 맞춰 확인합니다.

## 로드맵 갱신 규칙

1. 대상 분야·번호·제목과 선수 지식, 필수·심화 구분을 확인합니다.
2. 해당 템플릿으로 비공개 초안을 만들고 조사한 출처·범위를 기록합니다. Java는 독립 해설, Spring·Boot는 선별 번역으로 작성합니다.
3. 작성자가 초안을 읽고 예제를 확인하며 다듬습니다. 진행 상태의 별도 공개 요청이 없으면 공개 로드맵은 작성 전으로 유지합니다.
4. 문서 제출 단계에서 검토·빌드를 마치면 `draft: true`를 제거하고 작성 완료 상태와 실제 문서 링크를 함께 반영합니다. 기존 공식 자료 링크는 출처로 유지합니다.
5. 아직 작성하지 않은 항목은 번호를 조정할 수 있습니다. 이미 시작한 문서의 번호·경로·브랜치를 바꿀 때는 기존 작업을 먼저 확인하며 자동으로 이동하거나 삭제하지 않습니다.
6. 기준 원문을 갱신할 때는 해당 문서의 버전·원문 구간·검토일을 함께 확인합니다. 다른 버전의 설명을 조용히 섞지 않습니다.
