## 스레드와 동시성의 학습 흐름

스레드 생성·상태·중단부터 공유 상태와 동기화, 실행기·스레드 풀, Future·비동기 작업 조합, ThreadLocal, 가상 스레드까지 단계적으로 다룹니다. 병렬 스트림과 동시성 테스트 등 심화 항목은 기초를 익힌 뒤 돌아와도 됩니다.

전체 로드맵에서 각 글의 범위·공식 참고 자료·선수 지식과 필수·심화 구분을 확인합니다. 빌드 입문은 초반에, 기본 테스트 작성은 동시성 학습 전에 배치합니다.

## 작성 원칙

Java라는 이름 아래에는 Oracle Java 문서, OpenJDK 프로젝트 문서, dev.java 학습 자료처럼 저작권과 라이선스가 서로 다른 자료가 존재합니다. 따라서 하나의 라이선스로 묶어서 가져오지 않고 문서별 출처와 허용 범위를 먼저 기록합니다.

기준 예제는 Java 21로 작성하고, Preview·Incubator 기능과 전체 API 사전은 첫 범위에서 제외합니다.

자료 조사와 해설 초안을 마련한 뒤 작성자가 읽고 예제를 확인하며 다듬습니다. 여러 자료를 참고하더라도 원문 문단을 번역해 이어 붙이지 않습니다.
